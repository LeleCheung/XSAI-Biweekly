# XSAI 双周报一级分类参考（Biweekly 100-108）

## 分类表

| 一级分类 | 出现期次 | 适用内容 |
| --- | --- | --- |
| RTL 新特性 | 101、102、103、104、105、106、107、108 | 新指令、新数据类型、访存能力、缓存接口及硬件功能支持。 |
| Bug 修复 | 102、103、104、106、107、108 | 已定位的功能、控制、异常、性能事件或一致性问题修复。 |
| 代码质量 | 101、102、103、106、107、108 | 参数系统、构建或 elaboration 效率、代码组织和可维护性改进。 |
| 调试工具 | 101、106、107 | DiffTest、NEMU、trace 和测试环境等调试、验证能力建设。 |
| 评估工具 | 102 | 性能评估、仿真加速或评测流程能力建设。 |
| 代码重构 | 104 | 较大范围的模块结构或调度重构。 |

## 使用说明

- Biweekly 100 是 XSAI 架构与测试结果的专题介绍，未采用上述常规分类。
- 从 Biweekly 101 起，常规供稿使用 `### XSAI`，按实际进展选用分类；未涉及的分类不保留空标题。
- 每个二级条目只描述一项成果，可将同一项跨仓库改动合并为一条，并附全部关联 PR。
